## 📋 밋업 한눈에 보기

이 세션은 Microsoft 365 Copilot과 Copilot Studio를 활용해 업무용 프롬프트를 작성하고, 사전 빌드된 에이전트를 탐색한 뒤 직접 커스텀 에이전트를 만들어보는 실습 워크숍이다. 발표자는 집을 지을 때 전기공, 배관공, 목수처럼 전문 분야별 인력이 필요한 것에 빗대어 '왜 에이전트가 필요한가'를 설명했다. 참가자들은 Contoso Coffee Support라는 가상의 고객지원 에이전트를 이름, 설명, 지침(instructions), 지식 소스, 대화 시작 문구까지 직접 구성하며 실습했다. 다만 데모 계정의 라이선스 제한과 회사 네트워크 방화벽 때문에 실습 중 다수의 접속 문제가 발생했다.</br>

## 🔑 핵심 요점

- Copilot 프롬프트는 목표(Goal), 맥락(Context), 참고 자료(Source), 기대 결과(Expectation) 네 요소를 담을수록 품질이 좋아진다.
- 에이전트는 집을 지을 때 전기공·배관공·목수처럼 특정 작업에 특화된 전문가에 비유할 수 있다.
- Copilot Studio에는 Idea Coach, Prompt Coach, Career Coach 같은 사전 빌드 에이전트가 제공되며 '더보기(See more)' 메뉴에서 무료로 추가할 수 있다.
- 커스텀 에이전트는 이름, 설명, 지침, 지식 소스, 대화 시작 문구(conversation starter)로 구성된다.
- 지식 소스로 파일을 업로드하려면 기본 라이선스가 아닌 pay-as-you-go 결제 플랜이 필요하며, 이는 IT 관리자가 설정해야 한다.
- 파일 업로드가 불가능할 때는 대안으로 공개 웹사이트 URL이나 OneDrive 공유 링크를 지식 소스로 등록할 수 있다.
- 같은 채팅 세션 안에서는 에이전트가 지식 소스 문서를 최초 1회만 전체적으로 읽고 이후 응답에 재사용하며, 새 채팅을 시작하면 문서를 처음부터 다시 읽는다.

## 🛠 핵심 기술 쉽게 이해하기

### Microsoft Copilot Studio

대화형 AI 에이전트를 코드 작성 없이 만들 수 있는 Microsoft의 로우코드 빌더 도구다. 이름, 설명, 행동 지침, 지식 소스를 설정해 특정 업무에 특화된 챗봇을 구성할 수 있다.

**왜 필요한가** — 조직마다 필요한 특정 업무(고객지원, 반품 정책 안내 등)를 처리하는 전용 AI 도우미를 개발 지식 없이도 만들기 위해 사용한다.

**발표에서는** — 발표자는 참가자들과 함께 'Contoso Coffee Support'라는 고객지원 에이전트를 처음부터 만들면서 이름, 설명, 지침, 지식 소스, 대화 시작 문구 설정 과정을 시연했다.

### Microsoft 365 Copilot (Copilot Chat)

Microsoft 365 환경에서 문서 요약, 이메일 초안 작성 등 업무를 지원하는 AI 채팅 도구다. 프롬프트를 입력하면 그에 맞는 결과를 생성해준다.

**왜 필요한가** — 임원 보고용 요약처럼 형식과 분량이 정해진 업무 산출물을 빠르게 만들어내기 위해 쓰인다.

**발표에서는** — 발표 초반에 '임원 대상 요약 프롬프트'를 입력해 전략적 성과, 비즈니스 가치, 핵심 결정, 권고사항 위주로 150자 이내 요약을 생성하는 예시를 보여줬다.

### 사전 빌드 에이전트 (Idea Coach, Prompt Coach 등)

Microsoft가 미리 만들어 제공하는 특화 에이전트들로, 브레인스토밍을 돕는 Idea Coach나 프롬프트 작성을 도와주는 Prompt Coach 등이 있다. '더보기(See more)' 메뉴에서 무료로 내 목록에 추가할 수 있다.

**왜 필요한가** — 매번 처음부터 에이전트를 만들지 않고도 특정 상황(아이디어 발상, 좋은 프롬프트 작성 등)에 바로 활용 가능한 도구를 얻기 위함이다.

**발표에서는** — Idea Coach를 추가해 '고객 정보가 여러 시스템에 흩어져 있어 미팅 준비가 오래 걸린다'는 업무 문제를 입력하자, 자동화 아이디어와 관련 에이전트(예: meeting prep agent)를 제안하는 과정을 시연했다.

### 지식 소스 (Knowledge Source)

에이전트가 답변할 때 참고하는 문서나 웹사이트로, 에이전트의 '기억'과 같은 역할을 한다. 파일 업로드 또는 웹사이트 링크 형태로 등록할 수 있다.

**왜 필요한가** — 회사 반품 정책처럼 특정 정보에 근거해서만 답변하도록 에이전트의 지식 범위를 제한하고 출처를 명확히 하기 위해 사용한다.

**발표에서는** — 실습에서는 반품 정책 PDF를 업로드하려 했으나 라이선스 제약으로 실패했고, 대신 공개 웹사이트 URL을 지식 소스로 등록해 답변에 출처(citation)가 표시되는 것을 확인했다.

### Pay-as-you-go 라이선스 플랜

Copilot Studio의 일부 기능(파일 업로드 등)을 사용하려면 필요한 종량제 결제 플랜이다. 기본 라이선스로는 공개 사이트 링크만 지식 소스로 쓸 수 있다.

**왜 필요한가** — 무료/기본 라이선스로는 파일 기반 지식 소스 업로드가 제한되어 있어, 이를 해제하려면 결제 플랜 전환이 필요하다.

**발표에서는** — 다수 참가자가 파일 업로드 옵션이 보이지 않는 문제를 겪었고, 발표자는 이것이 라이선스 제한 때문이며 IT 관리자가 pay-as-you-go 플랜을 설정해야 해결된다고 안내했다.

## 🧭 추구 방향과 흐름

- **업무별 특화 에이전트(전문화)** — 발표자는 집 짓기 비유를 통해 한 사람이 모든 일을 하는 대신 전기공, 배관공, 목수처럼 각자 전문 분야를 맡는 것처럼, AI도 하나의 범용 챗봇 대신 브레인스토밍용, 프롬프트 작성용 등 목적별로 특화된 에이전트를 여러 개 두는 방향을 지향한다고 설명했다.
- **로우코드 시민 개발(Citizen Development)** — Copilot Studio는 코드 작성 없이 이름, 설명, 지침만으로 에이전트를 만들 수 있게 해, 비개발자인 업무 담당자도 직접 자신의 업무에 맞는 에이전트를 구축하도록 유도한다. 실습 세션 전체가 참가자들이 직접 고객지원 에이전트를 만들어보는 핸즈온 형식으로 진행됐다.
- **구조화된 프롬프트 작성(GCSE 프레임워크)** — 발표자는 좋은 프롬프트는 목표(Goal), 맥락(Context), 참고 자료(Source), 기대 결과(Expectation) 네 요소를 포함해야 한다고 강조하며, Prompt Coach 에이전트를 활용해 이 구조를 익히도록 안내했다.

## 🚀 바로 활용하기

1. Copilot Studio의 '더보기(See more)' 메뉴에서 Idea Coach, Prompt Coach 같은 사전 빌드 에이전트를 무료로 추가해 직접 사용해보기
2. 프롬프트를 작성할 때 목표(Goal)-맥락(Context)-참고자료(Source)-기대결과(Expectation) 네 요소를 의식적으로 포함시켜보기
3. 이름·설명·지침·지식 소스·대화 시작 문구 순서로 나만의 간단한 고객지원 에이전트를 직접 만들어보기
4. 파일 업로드가 막힌 환경이라면 OneDrive 공유 링크나 공개 웹사이트 URL을 지식 소스로 대체 등록해보기
